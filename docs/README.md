## 关于 01–04 的目录说明

01–04 写于原始 Vite 工程阶段，文中出现的 `src/`、`npm run data`、`npm run verify`、
`dist/index.html` 等路径与命令，指的是**那个工程**的组织方式。

本仓库发布的是它的构建产物（单文件 `index.html`），因此：

- 没有 `src/`，代码与数据都在 `index.html` 里；
- 数据以 `data/dataset.json` 为可编辑源头，用 `npm run build` 写回；
- 文中提到的 xlsx 源表属于课程实践材料，未随仓库分发；
- 但对账结论、数据契约、校验规则（V1–V12）、缺陷标记等**内容本身仍然有效**，也是理解 `dataset.json` 结构的依据。

新增的 [05](05-安卓安装与PWA方案.md) 属于本仓库发布形态，可直接照做。
