## 8. 复现步骤

```bash
cd D:\作业\工程信息管理\定额查询器v3
npm install            # Node 20+
npm run data           # xlsx → src/data/dataset.json（含 V1–V12）
npm run verify         # 独立对账，零差异则退出码 0
npm run dev            # http://localhost:5293
npm run build          # 产出 dist/（单文件 IIFE，可双击打开）
```

对账脚本输出应与本文 §2 完全一致；若原始 Excel 变更导致数字变化，以脚本结果为准并同步更新文档。
