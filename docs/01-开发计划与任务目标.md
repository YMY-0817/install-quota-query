## 1. 任务目标

### 1.1 一句话目标

把散落在两个 Excel、35 张工作表里的 2395 条定额消耗量记录，变成**一条可逐级点选的路径**：  
`分部（章） → 分项（小节） → 子目 → 人工/材料/机械消耗量明细`，在浏览器里 3 次点击内看到任意一个子目的完整人材机数据。

### 1.2 要解决的具体问题

| #  | 现状痛点  | 具体表现                                               | 本项目的解法                                    |
| -- | ----- | -------------------------------------------------- | ----------------------------------------- |
| P1 | 数据分散  | 2395 条记录散在 2 个文件、35 个工作表；问「6-160 用了多少人工」要开 36 个标签页 | 构建期一次性抽成 4 张关联表，前端内存索引                    |
| P2 | 无层级导航 | 长表只有"表名 + 子目编号"，没有分部/分项字段，无法按教材目录顺序找               | 由子目编号前缀推导章（分部），由工作表实名界定小节（分项），补齐 35 个分项标题 |
| P3 | 编号会撞车 | `2-92`～`2-98` 在多张工作表里重复出现，含义不同（`10m` vs `台`）       | 子目主键 = 工作表实名 + 编号，不用编号单列做主键               |
| P4 | 空值与负值 | 372 条消耗量为空、136 条为负（定额用负值表示扣减）                      | 空值渲染 `—` 且不计入合计；负值原样保留并标「扣减」              |
| P5 | 单位陷阱  | 子目单位是 `10m`／`100kg`／`10个` 这类定额单位，与自然单位差 10 倍       | 单位不换算、跨单位不给合计数                            |
| P6 | 数据不可信 | 表名章号与内容章号有 9 处不一致；3 张表内容逐格重复                       | 按编号归章；重复表用内容哈希识别并默认折叠；冲突在界面显式标注           |

### 1.3 成功判据（Definition of Done）

1. 任取 10 个子目，界面上的编号/名称/单位/逐条消耗量与原 Excel **逐格一致**；
2. 首屏打开即有内容，无需任何操作；
3. 从打开页面到看见目标子目明细，**不超过 3 次点击**（不含输入搜索）；
4. 数据对账脚本独立重读 xlsx，四层比对**零差异**；
5. 1440 / 1024 / 390 三档宽度无横向溢出、无遮挡；
6. 浏览器控制台 **0 error**；
7. 断网、双击 `dist/index.html` 仍可用。

### 2.3 原始长表 15 字段

`pkg_id`、`sheet_name`、`sheet_idx`、`subitem_code`、`subitem_name`、`subitem_unit`、`record_no`、  
`resource_type`、`resource_name`、`spec`、`resource_unit`、`consumption`、`note`、`owner_id`、`owner_name`。

两个文件表头与列序完全一致，可直接纵向合并。

### 2.4 四个必须绕开的坑（详见 docs/03）

1. **`sheet_name` 字段不可信**：`C3.8.1（3）（4）（5）` 三张表的该字段都写成 `C3.8.1`（共 222 行）；
2. **章号看编号不看表名**：9 张表的表名章号与内容章号不一致（如 `C5.9 (5)` 里装的是第 2 章电缆头）；
3. **3 张表内容逐格重复**：`C3.8.1（3）（4）（5）` 与 `C3.8.1` 内容哈希相同，不删除、标记后默认折叠；
4. **同编号不同含义**：`2-95`～`2-98` 在不同表里是「母线槽 / 10m」与「分线箱 / 台」，必须靠工作表名区分。

### 3.1 P0 —— 必须（缺一不算交付）

| 编号 | 功能                | 验收口径                                             |

## 4. 技术方案

### 4.1 架构分层

```
构建期（Node）            xlsx ──► build-data.mjs ──► src/data/dataset.json（4 张表 + meta.checks，被 Vite 内联进 bundle）
运行期（浏览器）          dataset ──► 模块加载时建索引 ──► 索引 / 搜索 / 详情装配
                                        ▲
UI 组件层                  App / TopBar / StepBar / DivisionRail / SectionColumn / ItemColumn / DetailPanel / SearchResults / ChecksDialog
```

| 决策     | 选择                                                            | 理由                                                     |
| ------ | ------------------------------------------------------------- | ------------------------------------------------------ |
| 数据落地方式 | 构建期转 JSON，不做实时解析                                              | 2395 条只需 500 KB；避免每次打开都跑 SheetJS 解析 xlsx（6 MB、约 2–4 秒） |
| 索引     | `Map<sectionId, Item[]>`、`Map<itemId, Consumption[]>`、预拼小写搜索串 | 切换 O(1)；全量搜索 O(2395)，实测 < 20 ms                        |
| 路由     | 自实现 hash 路由（约 30 行）                                           | 只需三段，不引 react-router                                   |
| 样式     | 原生 CSS + CSS 变量                                               | 单页无主题切换需求，减少依赖                                         |
| 状态     | `useState` + `useMemo`                                        | 数据量小，不引状态库                                             |

### 4.2 目录结构

```
定额查询器v3/
├─ docs/            01 开发计划 / 02 需求说明书 / 03 数据契约与筛选规则 / 04 验收报告
├─ scripts/         build-data.mjs（xlsx→json+校验）、verify.mjs（独立对账）
├─ src/data/        dataset.json（构建产物）、index.ts（索引/搜索/选中解析）
├─ src/

│  └─ styles/                  tokens.css、app.css

```

## 5. 风险与对策

| 风险                   | 影响                            | 对策                            |
| -------------------- | ----------------------------- | ----------------------------- |
| 误用 `sheet_name` 字段分组 | 3 张表被合并，子目 270 → 249，归属全错     | 分项主键一律用工作表实名，V10 断言           |
| 按表名归章                | 9 张表找错章，第 2 章记录从 1168 掉到约 300 | 归章 = 编号 `-` 前缀；冲突表打标          |
| 空值当 0                | 合计失真                          | `qty = null`，渲染 `—`，合计跳过并注明条数 |
| `10m` 与 `台` 混算       | 量级差 10 倍                      | 单位徽标 + 跨单位只给分布不给总数            |
| `record_no` 文本排序     | `10 < 9`，明细乱序                 | 构建期 `parseInt` 转数值            |
| 重复表被当重复录入            | 同一子目被算三次                      | 内容哈希识别，默认折叠，可开关               |
